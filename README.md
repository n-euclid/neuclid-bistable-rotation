# Neuclid Bistable Rotation Lab

An interactive Three.js exploration of ambiguous rotation, depth order, occlusion cues, and bistable perception.

The same projected motion can support more than one three dimensional interpretation. Rotate the scenes, reveal the central pillar, reverse the colour gradient, and compare opposing ribbon and helix configurations to inspect the geometry behind the illusion.

## Modes

1. One rotating ribbon.
2. Opposing ribbons shown side by side.
3. Ribbon arrows distributed across three axes.
4. Opposing double helices.

## Run locally

```bash
npm install
npm run dev
```

Then open the local address printed by Vite.

## Controls

Use the numbered controls to change modes. The circular controls reverse the colour scheme, reset the camera, reveal the pillar and orbit guides, record the screen and microphone, and enter full screen.

## Background

The project was prompted by [Ramin Nasibov's ambiguous rotating arrow](https://x.com/RaminNasibov/status/2092384791899386278). This repository contains an original Three.js implementation and does not redistribute the source video.
